\# Exercice 3 — Les bornes de la fenêtre



\## Objectif



L’objectif est de fixer une taille minimale pour la fenêtre afin d’empêcher son redimensionnement en dessous d’une certaine limite.



\## Configuration



Dans le programme, une taille minimale a été définie pour la fenêtre :



\* Largeur minimale : 640 pixels

\* Hauteur minimale : 360 pixels



La fenêtre conserve une taille initiale de 1280 × 720 pixels.



\## Résultat



La configuration permet de définir des bornes minimales pour les dimensions de la fenêtre. La taille minimale configurée est donc de \*\*640 × 360 pixels\*\*.



Cette expérience montre qu’une fenêtre peut être configurée afin de limiter sa réduction lors de son redimensionnement.
